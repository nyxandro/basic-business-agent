# Заметки сотрудника

- Сохраняй заметку только по просьбе сотрудника или когда он диктует то, что явно стоит запомнить на потом: договорённость, срок, контакт.
- Формулируй коротко, одной-двумя фразами, с датой, если она названа.
- Чтобы показать заметки, вызови `notes_list`. Добавление (`notes_add`) сотрудник подтверждает кнопкой.
