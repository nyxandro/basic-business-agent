# Системные скиллы

Скиллы, встроенные в ядро (спецификация, раздел 8.18; решение владельца 15.11.2026). Каждый — всегда включён у всех сотрудников: его нельзя выключить, заменить, сменить «Кому доступен» или удалить в админке. В базе их нет — источник здесь, меняются вместе с версией ядра.

| Папка | Что умеет агент | Название в админке |
|---|---|---|
| `docx/` | читать, создавать и править документы Word | Документы Word |
| `pptx/` | читать, создавать и править презентации | Презентации PowerPoint |
| `xlsx/` | читать, создавать и править таблицы, пересчитывать формулы | Таблицы Excel |
| `pdf/` | читать, создавать, объединять, заполнять формы, распознавать сканы | PDF |
| `letterhead/` | делать документы на бланке организации, строку подписи и метку для печати и подписи | Бланк организации |

Русские названия и описания для админки — в `manifest.ts`; модель видит исходные описания из `SKILL.md`.

## Откуда

`letterhead/` — свой скилл ядра (`docs/specs/[20.11.2026]-org-letterhead.md`), без скриптов: бланк без текста готовит сервер при загрузке, печать и подпись ставит инструмент `org_sign_document`.

Папки `docx/`, `pptx/`, `xlsx/`, `pdf/` — копия `skills/<имя>/` из https://github.com/anthropics/skills на коммите `1780c5e5a552fd4d1c9d6a7b0cab26b0c2bef064` (14.11.2026), **без правок**. Лицензия — Apache-2.0 (с 06.11.2026), полный текст — `LICENSE.txt` в каждой папке; авторство — в `NOTICE` репозитория.

## Что им нужно

Инструкции ждут установленными программы, библиотеки Python и пакеты Node (сети в песочнице нет, ставить им нечем). Состав — `core/sandbox/apt-packages.txt`, `core/sandbox/requirements.txt`, `core/sandbox/node/package.json`; сервер не запускается, если чего-то нет (`core/sandbox/environment.ts`).

## Как обновить

1. Взять новую копию папок целиком с нужного коммита, без выборочных правок.
2. Прочитать изменения `SKILL.md` и скриптов: новые программы, библиотеки и пакеты — добавить в состав песочницы и в образ; новые файлы-конфигурации в `/etc` — в `SANDBOX_SYSTEM_PATHS`.
3. Поменять коммит здесь и в `NOTICE`.
4. Прогнать `pnpm exec vitest run core/sandbox/sandbox.test.ts core/skills-admin` и `pnpm smoke`.

Новый системный скилл — папка с `SKILL.md` (поле `name` совпадает с именем папки) и строка в `manifest.ts`; без строки сервер не запустится.
