# Бланк организации, печать и подпись

Пути к бланку и логотипу, должность и ФИО руководителя и то, можешь ли ты ставить печать, — в разделе «Бланк, печать и подпись» системного промпта. Нет там строки «Бланк организации» — бланка нет: делай документ по скиллу `docx` как обычно.

## Когда на бланке

- На бланке: письма, коммерческие предложения, протоколы, справки, служебные записки, ответы на претензии — документы от имени организации.
- Не на бланке: договоры, акты, накладные, счета и документы по формам заказчика или контрагента — по этим формам; презентации и таблицы (в них — логотип); сотрудник прямо сказал «без бланка».

## Как сделать документ на бланке

Бланк — копия фирменного бланка без текста: колонтитулы, логотип, реквизиты и шапка уже на месте. Не делай новый документ через `docx` (npm) и не перерисовывай шапку — открой бланк и допиши текст:

```python
from docx import Document
from docx.shared import Pt

doc = Document('ПУТЬ_БЛАНКА')            # путь из системного промпта; бланк только для чтения
doc.add_paragraph('Уважаемый Иван Иванович!')
doc.add_paragraph('Текст письма…')
doc.save('КП-Вектор.docx')               # в рабочую папку, под понятным именем
```

- Текст ложится после шапки бланка и берёт его шрифты. Не меняй колонтитулы и то, что было в бланке до тебя.
- Заголовок: `doc.add_heading` падает с `KeyError`, если в бланке нет стиля заголовка, — тогда абзац жирным: `r = doc.add_paragraph().add_run('Коммерческое предложение'); r.bold = True; r.font.size = Pt(14)`.
- Таблица: `t = doc.add_table(rows=1, cols=3)`; `t.style = 'Table Grid'` тоже может дать `KeyError` — тогда без стиля, а границы — через XML:

```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

def borders(table):
    tbl_pr = table._tbl.tblPr
    b = OxmlElement('w:tblBorders')
    for side in ('top', 'left', 'bottom', 'right', 'insideH', 'insideV'):
        e = OxmlElement(f'w:{side}')
        e.set(qn('w:val'), 'single'); e.set(qn('w:sz'), '4'); e.set(qn('w:color'), '000000')
        b.append(e)
    tbl_pr.append(b)
```

- Проверь вид, как велит скилл `docx`: PDF через `soffice`, страницу — картинкой. Шапка бланка должна быть на месте.
- Нужен PDF — сначала готовый Word (с подписью, если её ставят), потом PDF из него.

## Строка подписи

Внизу документа — строка подписи руководителя: должность и ФИО — ровно как в системном промпте («Руководитель (главнее реквизитов)»), не из реквизитов и не по памяти.

- Печать и подпись не просили или ты их не ставишь — обычная строка: `Генеральный директор ____________ И. П. Иванов`.
- Сотрудник прямо попросил печать и подпись, и в системном промпте есть правило метки — отдельным абзацем на месте строки подписи ровно `[[ПОДПИСЬ_РУКОВОДИТЕЛЯ]]`, без должности и ФИО рядом: их напишет инструмент. Сохрани документ и вызови `org_sign_document` с путём файла и видом документа (`kind`):
  - `letter` — письмо, `commercial_offer` — КП, `minutes` — протокол, `certificate` — справка, `other` — другое;
  - `contract` — договор, `act` — акт, `waybill` — накладная: факсимиле на них допустимо, только если это предусмотрено договором с контрагентом — сотрудник увидит это в карточке «Да»;
  - `invoice_factura`, `upd`, `power_of_attorney` — счёт-фактура, УПД, доверенность: факсимиле на них не допускается. Метку не ставь и инструмент не вызывай — скажи, что такой документ подписывают от руки или электронной подписью.
- Называй вид честно: счёт-фактура — это `invoice_factura`, а не `other`.
- Инструмент ответил «нет метки» — поставь метку отдельным абзацем и вызови снова. Сотрудник сказал «Нет» — замени метку обычной строкой подписи, чтобы в документе не осталось `[[…]]`.
- После подписи покажи документ блоком файла.

## Логотип

Логотип — для презентаций, таблиц и документов без бланка: вставляй файл по пути из системного промпта, не перерисовывай его.
