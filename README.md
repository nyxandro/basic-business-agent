# basic-business-agent

Лёгкая открытая база, из которой под каждую организацию быстро собирается свой бизнес-агент:

- веб-чат с интерактивными ответами: таблицы, графики, формы;
- сотрудники с ролями и отделами, админка;
- учёт и лимиты расходов на модели;
- подключение к CRM и почте под личным доступом сотрудника;
- фоновые задачи по расписанию и событиям.

Стек: TypeScript, [Mastra](https://mastra.ai), CopilotKit 2 (AG-UI, A2UI), Better Auth, LiteLLM, Postgres, Docker.

**Состояние:** проектирование завершено, начинается реализация. Устройство и план — в [`docs/specs/[12.11.2026]-agent-base-architecture.md`](docs/specs/%5B12.11.2026%5D-agent-base-architecture.md).
